# SSC brand assets

The square icon and poster logo use the official Southern Surface Company vector artwork supplied for this portfolio. The icon isolates the existing monogram paths on the brand green background; its geometry is unchanged. The overview embeds the full white lockup as vector paths, without external asset requests.

`icon.svg` is the vector source for `../icons/southern-surface.png` (512 × 512). The same PNG is used in the GitHub profile. The showcase repository keeps an identical, self-contained overview illustration.
