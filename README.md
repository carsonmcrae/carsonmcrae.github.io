# Carson McRae

A static portfolio of product work: PicPledge and Recalen case studies, plus TTSNative, an open-source app (formerly Local TTS), and a case study of how its studio voice was evaluated.

Visit https://carsonmcrae.github.io/.

The case studies describe products owned, designed, and developed by Carson McRae. PicPledge's and Recalen's application source is private; TTSNative's is public at https://github.com/carsonmcrae/ttsnative.

## Editing

The pages are plain HTML and CSS, edited directly; there is no build step. When `styles.css` changes, set the `?v=` value in every page's stylesheet link to the first 12 hex digits of the file's SHA-256, so browsers fetch the new version.
